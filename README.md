# منظومة شئون طلاب الجامعات الخاصة والأهلية
### تطبيق التنسيق الأكاديمي وسحب ملفات الطلاب والداشبورد اللحظية
**تصميم وبرمجة: مهندس بولس سمير - مدير شئون الطلاب - جامعة اللوتس بالمنيا**

---

## 🌟 نظرة عامة على المنظومة المحدثة
منظومة سحابية متكاملة واحترافية صُممت خصيصاً لإدارة وتنسيق سحب ملفات الطلاب بين مسئولي شئون الطلاب في الجامعات الخاصة والأهلية في جمهورية مصر العربية. 

يتيح النظام الآن **لكل موظف تسجيل حساب مستقل** وامتلاك **داشبورد خاصة به**، تُمكّنه من:
1. **استقبال كشوفات الطلاب الواردة لجامعته** المطلوب سحب ملفاتهم، ومراجعة الأسماء، ووضع علامة صح (اتشيك تم السحب) لكل طالب، مع خانة ملاحظات حرة لكل طالب.
2. **إرسال كشوفات الطلاب المحولين أو المسحوبين** لأي جامعة أخرى بنقرة واحدة، لتصل فوراً لمسؤول تلك الجامعة في المنظومة.
3. **مركز إشعارات فوري لحظي**: عند قيام مسؤول الجامعة الأخرى بتغيير حالة أي طالب أو إضافة ملاحظة عليه، يصل إشعار فوري للموظف المرسل لمتابعة الحالات أولاً بأول، مع تنبيه صوتي وشارة إشعارات نابضة.
4. **المزامنة السحابية الفورية** عبر **Firebase Realtime Database** مع دعم العمل دون إنترنت بذاكرة احتياطية محلية (LocalStorage Fallback).

## 🚀 المميزات الرئيسية للمنظومة

### 1. نظام حسابات الموظفين وتسجيل الدخول:
- **تسجيل حساب موظف جديد**:
  - الاسم ثلاثي (مع تحقق ذكي من 3 مقاطع على الأقل).
  - رقم الموبايل (واتساب مصر: 010 / 011 / 012 / 015).
  - الجامعة التابع لها (قائمة بحثية تضم كافة الجامعات الخاصة والأهلية المصرية مع إمكانية كتابة أي جامعة يدوياً).
  - المسمى الوظيفي وكلمة المرور.
- **تسجيل الدخول وإدارة الجلسات**:
  - حفظ جلسة الموظف النشطة في المتصفح تلقائياً.
  - إمكانية تسجيل الخروج أو تبديل الحساب بسهولة.
  - ترويسة شخصية تعرض اسم الموظف وجامعته وأفاتار مخصص.

### 2. لوحة التحكم المخصصة لكل موظف (Personalized Dashboard):
- **كروت المؤشرات والإحصائيات اللحظية (KPIs)**:
  - عدد الكشوف الواردة لجامعتي.
  - إجمالي الطلاب المطلوب سحبهم من جامعتنا.
  - عدد ونسبة الطلاب الذين تم سحب ملفاتهم بالفعل من جامعتنا (نسبة الإنجاز المئوية).
  - عدد الكشوفات الصادرة مني للجامعات الأخرى.

- **التبويب الأول: 📥 الكشوف الواردة لجامعتي**:
  - استعراض الكشوف المرسلة من الجامعات الأخرى إلى جامعة الموظف الحالي.
  - بطاقة لكل كشف توضح: الجامعة المرسلة، اسم المسؤول، رقم هاتفه مع زر اتصال وواتساب، وتاريخ الإرسال.
  - **زر الحالة (اتشيك تم السحب)**: نقرة واحدة لتبديل حالة الطالب بين `[تم السحب ✅]` و `[قيد السحب ⏳]`.
  - **خانة الملاحظات**: حقل إدخال مرن يكتب فيه مسؤول الجامعة أي ملاحظات (مثل: "تم تسليم الملف لولي الأمر", "عليه رسوم بالخزينة", إلخ) مع حفظ تلقائي وسحابي فوري!
  - **زر تقرير واتساب**: يرسل تقريراً محدثاً بالواتساب للموظف المرسل بحالة كل طالب وملاحظاته.
  - **زر طباعة الكشف 🖨️**: يفتح نموذجاً رسمياً معتمداً للتوقيعات الإدارية جاهزاً للطباعة.

- **التبويب الثاني: ➕ إرسال كشف سحب جديد**:
  - اختيار الجامعة المستهدفة المراد سحب ملفات الطلاب منها، مع إظهار بيانات مسؤولها تلقائياً.
  - مساحة كبيرة لإدخال أو لصق أسماء الطلاب (تدعم النسخ من Excel أو Word).
  - **الترقيم التلقائي التسلسلي (1. 2. 3.)**: تنظيف الرموز وتجريد الزوائد بلمسة واحدة.
  - إرسال سحابي فوري يرسل إشعاراً لمسؤولي الجامعة المستهدفة + إمكانية إرسال نسخة رسمية بالواتساب.

- **التبويب الثالث: 📤 متابعة كشوفاتي الصادرة (المتابعة الحية)**:
  - استعراض كافة الكشوفات التي أرسلها الموظف للجامعات الأخرى.
  - شريط تقدم يوضح نسبة إنجاز سحب الطلاب لكل كشف.
  - جدول تفصيلي يوضح حالة كل طالب (تم السحب ✅ أو قيد المراجعة ⏳).
  - **عرض الملاحظات التي كتبها مسؤول الجامعة الأخرى** على كل طالب بوضوح تام!

- **التبويب الرابع: 📖 دليل مسؤولي الجامعات والسجل العام**:
  - الدليل الشامل لكافة الجامعات الخاصة والأهلية بمصر للاتصال والنسخ والتنسيق المباشر.

### 3. مركز الإشعارات الحية (Realtime Notification Center):
- جرس إشعارات في الترويسة مع شارة عدد الإشعارات غير المقروءة وأيقونة متحركة.
- نغمة تنبيه صوتية لطيفة (Web Audio API) تنطلق فور وصول أي تحديث جديد.
- إشعار فوري يظهر للموظف المرسل عند:
  - قيام موظف الجامعة الأخرى بتأكيد سحب أي طالب (`isCompleted: true`).
  - قيام موظف الجامعة الأخرى بإلغاء سحب أي طالب أو كتابة ملاحظة جديدة عليه.
  - ورود كشف جديد لجامعة الموظف من جامعة أخرى.
- زر "تحديد الكل كمقروء" وإمكانية النقر على الإشعار للانتقال المباشر للكشف.

### 4. لوحة تحكم الإدارة المركزية (Super Admin - PIN: 8520):
- النقر المزدوج على العنوان الرئيسي يفتح نافذة الدخول بالرقم السري `8520`.
- إحصائيات شاملة على مستوى كافة الجامعات في جمهورية مصر العربية.
- استعراض وتعديل وحذف أي سجل أو كشف.
- **تصدير تقرير شامل إلى ملف Excel (CSV مع UTF-8 BOM)** لضمان وضوح اللغة العربية بنسبة 100%.

## 📂 ملفات المشروع
- `index.html`: هيكل التطبيق والشاشات والداشبورد والمودالات.
- `style.css`: الأنماط الفخمة، التأثيرات الزجاجية (Glassmorphism)، البطاقات، وأنماط الطباعة.
- `universities-data.js`: قائمة شاملة ومحدثة للجامعات الخاصة والأهلية المصرية.
- `firebase-service.js`: محرك المزامنة السحابية وقواعد البيانات وإدارة الحسابات والكشوفات والإشعارات.
- `app.js`: منطق التفاعل، الداشبورد الشخصية، التحقق، الترقيم التلقائي، والربط اللحظي.
